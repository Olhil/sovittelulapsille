# Privacy Policy & Data Protection Manifesto

**Sovittelu Lapsille** is built on the principle of **Radical Local-First Privacy by Design**. Sensitive conversations of children and families never leave the user's device.

## 1. Zero Data Collection
* **No Backend Servers:** No server infrastructure receives, processes, or stores user inputs.
* **No User Accounts:** Immediate access without registration, names, emails, or identifiers.
* **No Analytics or Telemetry:** Zero cookies, zero tracking scripts, zero crash-reporting SDKs, and zero third-party CDNs or external fonts.

## 2. On-Device Storage & Shared-Device Hygiene
* **Local Browser Storage Only:** Session progress stays strictly inside local browser memory (`localStorage`) for offline use.
* **Ephemeral State & Instant Wipe:** Built for shared tablets in libraries and schools with instant one-tap session reset and automatic state sanitization.

## 3. Local Audio Narration (Zero-Cloud Speech)
* Optional read-aloud support uses the browser's built-in **Web Speech API** (`window.speechSynthesis`) with local OS voice packs. No text or audio is sent to the cloud.

## 4. Regulatory Compliance
Because **Sovittelu Lapsille** collects and transmits zero personal data, it is compliant by design with the **EU GDPR** and international child online safety standards.
