# Sovittelu Lapsille / Conflict Mediation Tool (Prototype)

**Live Demo:** https://sovittelulapsille.pages.dev  
*(Note: The current prototype interface is in Finnish / Suomi).*

## Overview
An open-source, privacy-first web application designed to guide children, families, and educators through structured conflict de-escalation and self-mediation. Built upon over a decade of practical mediation experience in Helsinki (handling 200+ cases annually since 2013) and validated through Montessori early childhood education pilots, this tool translates proven restorative communication methodologies into an accessible, everyday digital format for schools, libraries, and homes.

This is an independent, non-commercial open-source initiative.

## Core Principles & Architecture
* **Zero Tracking & Absolute Privacy:** Runs 100% locally in the user's browser (`localStorage`). No accounts, no databases, no external servers, and zero collection of sensitive emotional or personal data.
* **Zero-Waste & Sustainable Tech:** Operates completely without cloud AI inference or token consumption, eliminating ongoing compute costs, water/energy overhead, and vendor lock-in.
* **Offline-First & Lightweight:** Engineered as a static Progressive Web App (PWA) accessible via a simple QR code, ensuring long-term resilience and zero maintenance overhead.
