# Accessibility Statement

**Sovittelu Lapsille** is committed to providing a calm, inclusive, and barrier-free conflict mediation tool for children, families, and educators—including pre-readers, screen-reader users, and neurodivergent individuals (ADHD, autism spectrum, and dyslexia).

## Target Standards & Features
We are actively engineering the application to meet **WCAG 2.1 / 2.2 Level AAA** guidelines:
* **Low-Stimulation UI:** Calm color palettes, generous spacing, clear typography, and zero flashing animations or distracting notifications.
* **Screen-Reader & Keyboard Support:** Semantic HTML5 landmarks, ARIA attributes, and full keyboard navigability.
* **Zero-Cloud Audio Narration:** Built-in read-aloud support using the browser-native Web Speech API (`window.speechSynthesis`) to assist pre-readers and dyslexic users without external tracking.
* **Offline & Low-End Device Compatibility:** Lightweight static architecture designed to run smoothly on shared school and library tablets.

## Supported Environments
Tested on current versions of **Chrome/Chromium**, **Firefox**, **Safari (iOS & macOS)**, and **Edge** across mobile phones, tablets, and desktop computers.

## Feedback & Reporting Barriers
If you encounter any accessibility barriers or have suggestions to improve usability for children or neurodivergent users, please open an issue in this repository or contact the project maintainer via the contact details listed in the repository profile.
